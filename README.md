# Thauma

Цифровая упаковка подарочных сертификатов с анимацией открытия и личным аудиопоздравлением.

Frontend: GitHub Pages, branch `main`, root `/`.

Отправка между устройствами: Cloudflare Worker + закрытое R2-хранилище.
Инструкция запуска и проверок: [backend/README.md](backend/README.md).

Сервер Cloudflare подключён через `assets/sharing-config.js`. При создании подарок сохраняется в R2, и получатель может открыть случайную ссылку на другом устройстве без регистрации.
Предпросмотр и старые демо-ссылки сохраняются локально в браузере. Пустой API_BASE позволяет вернуться к локальному демо.

Срок доступа — 30 дней. Сертификат и аудио: до 25 МБ каждый, до 30 МБ вместе.
